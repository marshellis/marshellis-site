# Driving Empire

Open-world driving sandbox on Three.js: a 5.6 km map with a city, nine country towns, ~64 km of road, a river, lakes, a snow-capped range and a desert,
sixteen real-brand cars you buy with money earned by driving, races, jobs, drifting, and a day/night + weather cycle (a day lasts about 15 minutes).

This folder is the production build (static files, no server needed; single-player). The source lives in the private repo `marshellis/driving-empire`.

## Controls

| Key | Action |
| --- | --- |
| W / S, A / D | throttle / brake / reverse, steer |
| Space | handbrake (with a turn at speed it starts a drift) |
| Shift | nitrous boost |
| V, M, O | camera, world map, settings |
| E | start a race or job at an orange marker |
| R | recover the car |
| B | talk to the car salesman (inside the Golden Dome, city centre) |
| 1-0 | teleport around the map |
| H | full help |
